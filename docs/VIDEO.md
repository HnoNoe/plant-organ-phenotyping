# 视频 → 点云：拍摄与重建指南

本仓库的视频扫描工具链（`tools/`）把"绕物体拍一段视频"变成"稠密三维点云"，
是器官级管线（掩码 → 跨视图匹配 → 表型）的上游数据采集段。

## 工具

| 工具 | 作用 |
|------|------|
| `tools/scan_video.py` | 视频 → 抽帧 → COLMAP 稀疏+稠密重建 → `fused.ply` |
| `tools/extract_green.py` | 按颜色从点云筛出绿色植物点（npy + 核验图） |
| `tools/analyze_plant.py` | 密度峰定位中央植株 → 裁剪 → 体素聚类（叶片候选）→ 几何统计 |

## 快速开始

```bash
# 依赖：ffmpeg、COLMAP（带 CUDA，PATH 可找到；版本可用 --colmap-bin 指定）
python tools/scan_video.py --video plant.mp4 --out recon1
python tools/extract_green.py recon1/dense/fused.ply recon1/cloud
python tools/analyze_plant.py recon1/dense/fused.ply recon1/vid1 --radius 1.2
```

## 拍摄规范（决定成败）

1. **数量靠抽帧**：20–30 秒连续环绕视频，按 2.5 fps 抽帧可得 50–80 张，
   相邻帧视角差小，匹配天然密集（视频帧用 sequential 匹配器，比离散照片稳得多）。
2. **速度**：手移动要慢而匀速，每圈 15–25 秒；移动太快会运动模糊。
3. **构图**：目标占画面 1/3 以上；想做到叶片/器官级，目标要占画面一半以上。
4. **稳定性**：物体绝对不能动（风吹的叶子是大敌）；手持可以，但脚步要稳。
5. **光照**：均匀自然光最好；避免逆光和大面积反光。
6. **尺度**：想拿到真实尺寸，画面里放一把尺子——重建后用已知长度做尺度归一。

## 已知边界

- 单目重建只给**相对尺寸**，厘米级真实值需要画面内参照物做尺度归一。
- 远距离、目标占比小的视频只能到"冠层级"几何；器官级需要近距离视频 + 实例掩码
  （见主 README 的管线入口）。
- 无纹理/强反光/透明物体（玻璃、漆面）是 SfM 的天敌，重建会失败或严重缺失。
